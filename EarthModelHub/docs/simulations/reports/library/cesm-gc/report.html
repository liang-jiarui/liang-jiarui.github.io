Implementation and evaluation of the GEOS-Chem chemistry module version 13.1.2 within CESM v2.1

模型：CESM–GEOS-Chem；年份：2022；DOI：10.5194/gmd-15-8669-2022。

论文全文 · 本地 PDF · 作者代码 · 任务配置 · Gallery

作者用来出图的是 CESM-GC v1.0.0_review，CESM 2.1.1，GEOS-Chem 13.1.2。本机带 GEOS-Chem 化学的源码是 CESM 2.3 alpha17e。GCHP 13.1.2 没有安装。下面的 case 是按论文 §3 和 Table 6 写的草案。

三套配置共用 2016 日历年做比较。C-GC 和 C-CC 先积 1 年自旋，S-GC 先积 6 个月。排放都经 HEMCO。C-GC 与 C-CC 的气象是 MERRA-2 规定动力，松弛时间 50 h；水汽在初始化之后由 CAM 物理计算。S-GC 除平流层比湿外，气象直接取 MERRA-2。

库存 FCnudged_GC 是另一套做法：32 层 MERRA-2 松弛，use case 里 U、V、T 的系数是 0.06。按 6 小时一次分析，这个系数对应的时间尺度是 100 h，而且不松弛地面气压。论文写的是规定动力和 50 h，所以 E01 用带 %SDYN 的长名，并在 user_nl_cam 里把 met_rlx_time 设为 50。这条长名还没有库存 use case，56 层也不会由现有的 -nlev 规则自动加上。

E02 的别名 FCSD_HCO 会选 sd_trop_strat_vbs_cam6，其中已经是 met_rlx_time = 50 和 56 层。气象文件只登记了 0.9x1.25 和 0.47x0.63。案例仍按论文写成 f19_f19_mg17。
