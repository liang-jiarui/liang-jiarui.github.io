Experiment workflows

Activate the project environment and run these commands from the repository root. Submit jobs through the relevant Hub in a configured HPC environment.

Simulation tasks

List registered simulation tasks.

python3 scripts/earthmodel.py --list

Preview the run plan for the E3SM ne30 group in the 2023 fire comparison.

python3 scripts/earthmodel.py xu_2026_fire_2023 --groups e3sm/ne30 --dry-run

Machine learning experiments

List registered experiments and configurations.

python3 deps/MachineLearningHub/scripts/mlhub list

Start the workbench and open it on the same machine to submit experiments and view their status and results.

(cd deps/MachineLearningHub && python3 -m src.ml.ui --server.address 127.0.0.1 --server.port 8501)
