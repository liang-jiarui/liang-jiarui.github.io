    01 · 安装与快速运行¶

    科学核心和单次模拟只需要支持 C++20 的编译器与 CMake 3.20 或更新版本。以下命令以常见的 Linux shell 为例，用 GCC 13.4 和 CMake 3.31 验证过。整组运行另需 Python 3，绘图和生成文档站需要 requirements-docs.txt 中的依赖。示例强迫已随仓库保存，本地积分可以离线运行。

    构建与自检¶

    在源码根目录运行以下命令。-DCMAKE_BUILD_TYPE=Release 选用优化构建，CTest 会执行平衡、解析解、收敛和预算检查。

    cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/ebm0d --version

    如果系统自带的编译器太旧，可以在首次配置时用 -DCMAKE_CXX_COMPILER=/path/to/g++ 指定新工具链。若已经生成过 CMake 缓存，给新编译器使用另一个构建目录，例如 build-gcc13，并替换下文的可执行程序路径。

    第一次积分¶

    ./build/ebm0d experiments/ebm0d/piControl.cfg runs/piControl
head -n 3 runs/piControl/timeseries.csv
cat runs/piControl/manifest.txt

    piControl 的首末温度均为 288 K。输出目录由程序创建，每次运行指定一个新的目录，以便保留先前结果。manifest.txt 在其他文件全部成功写入后生成，用于识别完整运行。case.cfg 是程序保留的配置副本，可直接用来重跑。

    ./build/ebm0d runs/piControl/case.cfg runs/piControl-repeat
cmp runs/piControl/timeseries.csv runs/piControl-repeat/timeseries.csv

    四倍 CO₂ 实验可以用 ./build/ebm0d experiments/ebm0d/abrupt-4xCO2.cfg runs/abrupt 启动。对照第一行的 co2_ppm、temperature_start_k 和 temperature_end_k，可以直接看到步首强迫如何推进温度。实验配置说明

    整组运行¶

    python3 tools/run_ebm_suite.py --executable build/ebm0d --output runs/ebm0d

    这条命令运行并校验六个实验，在 runs/ebm0d/ 中保存各实验的逐步结果、年聚合结果和汇总。需要复跑时可改用 --output runs/ebm0d-repeat。下表列出最常看的文件。

    文件 内容
    <case>/timeseries.csv 每一步的温度、CO₂、辐射和热储存变化率
    <case>/case.cfg、<case>/manifest.txt 重跑所需的配置与模式、编译器、积分方法记录
    <case>/forcing.csv 年表案例实际使用的浓度
    summary.csv、annual.csv、diagnostics.csv 终点汇总、逐年聚合、热响应与时间尺度

    本地预览完整教程¶

    先创建 Python 环境，再用实跑结果生成网页所需的图表和下载包。

    python3 -m venv .venv-docs
source .venv-docs/bin/activate
python -m pip install --prefer-binary -r requirements-docs.txt
python tools/run_ebm_suite.py --executable build/ebm0d \
  --output runs/ebm0d-docs --figures docs/tutorial/generated
python -m mkdocs build --strict
python -m mkdocs serve

    默认预览地址是 http://127.0.0.1:8000/。构建产物位于 site/，从其中的 tutorial/index.html 可以看到教程入口。已经生成过图表时，可直接执行 MkDocs 构建或预览。
