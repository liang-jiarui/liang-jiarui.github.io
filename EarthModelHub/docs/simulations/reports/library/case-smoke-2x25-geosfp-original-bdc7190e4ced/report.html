Smoke test

GC-adjoint v36 · GEOS-FP 2°×2.5° 正向短测报告

目的与范围

检查原版 GC-adjoint v36 能否直接读取 2°×2.5° GEOS-FP 气象场，完成 3 小时的被动 CO 正向输送，并写出可读的诊断和重启。

实验设置

项目 配置
构建 原版 GC-adjoint v36
气象 GEOS-FP，使用原版读取器
网格 全球 2°×2.5°，144 × 91 × 72
时段 2013-07-01 00:00 至 03:00 UTC
示踪物 被动 CO，仅正向输送

验收与结果

算例正常退出，返回码为 0。按同目录 validation.json 的记录，三个输出各含一个数据块，均覆盖 03:00 UTC 的积分终点。

输出 数值个数 非有限值个数
ctm.bpch 943,488 0
restart.geos5.2013070103 943,488 0
restart.psc.2013070103 773,136 0

终点 CO 浓度范围为 99.996328–100.000001 ppbv。

适用范围

本次验收覆盖首个 3 小时气象窗口内的正向输送、诊断和重启。更长积分、伴随回算与梯度对比需要各自的验收。
