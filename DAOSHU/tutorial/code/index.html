    05 · 代码导读与测试¶

    从一次实验反向阅读代码。先看配置如何指定参数和强迫，再沿驱动程序找到单步积分，最后用测试中的参考解检查物理与数值实现。

    文件分工¶

    文件 建议从这里看起
    实验配置 六组实验的初始条件、时长、浓度路径与参数
    独立驱动 apps/ebm0d.cpp 读配置、选择逐步浓度、调用科学核心、写输出
    科学接口 ebm0d.hpp Parameters、Fluxes、StepResult 和物理函数签名
    科学实现 components/ebm/ebm0d.cpp 参数验证、辐射通量、前向 Euler 与预算残差
    核心测试 ebm0d_test.cpp 如何把解析解、极限情况与物理不变量写成可运行的检验
    构建入口 CMakeLists.txt C++20、核心、可执行程序与 CTest 的构建关系
    实验脚本 run_ebm_suite.py 运行六组实验、校验输出、做年度汇总并生成结果页图表

    跟一遍计算顺序¶

    实验配置与输出路径
        ↓
独立驱动读取参数并建立模型时钟
        ↓
步首时间 ────→ 该步的指定 CO₂
        ↓                ↓
步首温度 + CO₂ + 参数 + 步长
        ↓
step(...) → 步首通量、步末温度和收支诊断
        ↓
写入输出，步末温度成为下一步的步首温度

    要核对时钟和强迫，先看驱动。要核对一个时间步里的能量项，查 components/ebm。科学核心的输入由调用者传入，因而单元测试可以构造几行参数并直接调用 step(...)。

    驱动如何选浓度¶

    load_experiment 读取必需参数，检查配置键和强迫模式。每行配置采用 key = value，# 之后可以写注释。未知键、重复键、缺省键都会触发错误，避免因拼写错误无意间使用另一套参数。years 与 steps_per_year 共同决定时间步数，initial_temperature_k 给出实际初温。

    forcing 值 配套键 co2_at_step 的计算
    fixed co2_multiplier reference_co2_ppm × co2_multiplier
    compound co2_annual_growth reference_co2_ppm × (1 + co2_annual_growth)^(n/steps_per_year)，其中 n 从 0 起算
    annual_table start_year、co2_file 按当前年份读浓度表，同一年各步共用一个值

    年表模式从配置文件所在目录解析相对路径 co2_file，表头为 year,co2_ppm。从 start_year 起按年份顺序写，每年一个正浓度值，并覆盖 years 指定的完整区间。

    逐个看接口¶

    • Parameters 保存数值与单位约定。字段后缀用于区分 K、ppm、W m⁻² 和 J m⁻² K⁻¹。基准值见科学原理。
    • validate(parameters) 检查物理参数范围。反照率在 0 与 1 之间，温度基准、热容量、反馈系数和参考浓度为正。CO₂ 强迫系数可设为零，以便做关闭强迫的对照。
    • fluxes(temperature_k, co2_ppm, parameters) 计算短波、长波、CO₂ 强迫和净通量。实现把公共的参考短波和长波通量在代数上消去后求净值，避免两项很接近时相减丢失小的失衡信号。
    • step(temperature_k, co2_ppm, parameters, dt_seconds) 先计算步首通量，再积分更新温度。它从实际返回的温度变化计算热储存变化率和收支残差，便于定位浮点误差。

    StepResult.temperature_k 是步末温度，StepResult.start_fluxes 保留该步所用通量。比较预算或重做通量回归时，需要把被驱动的时间区间与对应的步首通量配在一起。

    输出的溯源信息¶

    • timeseries.csv 每行对应一个积分步。首行的 step 为 1、elapsed_start_years 为 0，temperature_start_k 是配置中的初温。末行的 elapsed_end_years 等于实验时长。year 是步首所属的整数年，理想化实验从 1 起算，年表实验从 start_year 起算。
    • case.cfg 保存整理后的配置。年表案例还写出本次实际使用的 forcing.csv，并在配置副本里指向该文件。要用同一可执行程序重跑，可将这个配置副本作为输入，将另一条新路径作为输出。
    • manifest.txt 保存模式版本、源文件 SHA-256 摘要、编译器、历法、积分方式和输出规格版本。源文件摘要由构建入口、独立驱动、科学接口和实现计算，可与 ./build/ebm0d --version 打印的摘要核对。配置和输入浓度另由前述副本记录。

    读图分析的列选择和温度异常定义见实验结果。

    运行和理解测试¶

    在仓库根目录构建后执行 CTest。调试时可先用 ctest --test-dir build -N 查看可运行的测试。

    cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
    核心测试 核对关系
    radiative_fluxes 参考温度下吸收短波约为 238.175 W m⁻²，净通量为零。四倍 CO₂ 的对数强迫是倍增强迫的两倍。
    control_equilibrium 参考态稳定，偏暖的控制初态向平衡回落。
    abrupt_4xco2_convergence 十年末温度与解析解对比。步长减半后误差比约为 2，各步预算残差在指定容差内。
    input_validation 核对参数、温度、浓度和时间步的边界，包括时间步达到单调性上限的情形。

    收支闭合和时间精度检验的是不同性质。每一步都可能精确地执行一个近似的离散更新。解析解和步长收敛能检查随模拟时间累积的离散误差。

    实验脚本再从正常命令行入口验证六组配置。它检查步数、时间标签、相邻时间步温度连续性、能量残差，并检验两条 SSP 在 1850–2014 的输出逐行等于历史实验。测试通过后才汇总数据和作图。执行方式见实验协议。

    自学练习¶

    1. 按科学原理手算四倍 CO₂ 第一时间步的温度，再找到代码里实现的每一项。
    2. 从测试中的 integrate_abrupt_4xco2 开始，找出十年积分的解析温度、粗细步长以及误差比。尝试把粗细步数各加倍，看看误差比如何变化。
    3. 比较两份配置，一份使用基准参数，一份只把 CO₂ 强迫系数设为零。逐项解释模型读到的相同和不同输入，以及为什么温度曲线不同。
