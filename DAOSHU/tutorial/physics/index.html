    02 · 科学原理与数值积分¶

    在 DAOSHU M0 中，整个地球系统由一个全球平均温度 T 表示。沿着吸收太阳辐射、发射长波辐射、温度变化这条链，可以直接追踪地球能量的净收入。“零维”指模式只有时间轴，无水平或垂直坐标。

    从太阳辐射到能量收支¶

    设太阳辐照度为 S，行星反照率为 α。地球拦截太阳辐射的截面积是 πR²，地球总表面积是 4πR²，因此吸收的全球平均短波通量是 SW = S(1 − α)/4。反照率表示直接反射到太空的份额。

    长波通量采用以参考态为中心的线性近似 OLR(T) = SW + λ(T − Tref)。参考温度处的长波常数项等于吸收短波，使参考态的辐射收支闭合。正的 λ 表示升温会增加向外长波，进而减小地球的净能量收入。这里 λ 是一个可设定的净反馈强度。

    CO₂ 强迫采用对数近似 F = a ln(CO₂/CO₂ref)，其中 ln 为自然对数。浓度与参考值相同时 F = 0。浓度高于参考值时，正强迫增加地球系统的能量收入。每次翻倍带来的强迫增量都等于 a ln(2)。系数 a = 5.35 W m⁻² 取自经典近似。Myhre et al. (1998)

    把三项合在一起得到大气顶净向下通量 N 和温度方程。

    N = SW − OLR(T) + F = F − λ(T − Tref)
C dT/dt = N

    C 是按地球总表面积归一化的有效热容量。对一个给定的正 N，C 越大，升温越慢。温度用 K，时间导数的时间单位用秒，所以 C dT/dt 的单位是 J m⁻² s⁻¹，也就是 W m⁻²。温差 1 K 等于温差 1 °C。

    符号 含义 基准值 单位
    S 太阳辐照度 1,361 W m⁻²
    α 行星反照率 0.30 无量纲
    Tref 参考温度 288 K
    CO₂ref 参考 CO₂ 干空气摩尔分数 284.317 ppm
    a CO₂ 对数强迫系数 5.35 W m⁻²
    λ 线性辐射反馈强度 1.2 W m⁻² K⁻¹
    C 有效热容量 2.1 × 10⁸ J m⁻² K⁻¹

    表中的参数组是 M0 的教学基准。对于该组参数，SW ≈ 238.175 W m⁻²，CO₂ = CO₂ref 时的平衡温度是 288 K。在当前长波定义下，修改 S 或 α 会同步改变短波和参考长波通量。研究太阳变化或反照率反馈时，需要为长波常数项保留独立的参考值，并把短波扰动显式加入预算。

    用解析解理解实验¶

    持续施加同一个强迫 F 时，平衡要求 N = 0，因此 Teq = Tref + F/λ。用时间尺度 τ = C/λ 可以写出任意初温 T0 的连续解。

    T(t) = Teq + (T0 − Teq) exp(−t/τ)

    基准参数给出约 5.55 年的响应时间尺度。运行一个 τ 后，初态与新平衡之间的温差余下约 37%。持续 4×CO₂ 时，初始强迫约为 7.417 W m⁻²，最终升温约 6.181 K。在当前线性反馈式中，平衡倍增升温由参数直接决定，约为 3.090 K。

    渐增 CO₂ 实验在模型时钟 y（年）上的浓度为 CO₂ref × 1.01^y。对数强迫因此以约 0.05323 W m⁻² yr⁻¹ 的固定斜率增长。温度因热容量而落后于随强迫移动的瞬时平衡温度。可用本文的时间尺度解释落后量，也可把输出与实验结果对照。

    从连续方程到每一步更新¶

    前向 Euler 在步首读取温度和强迫，然后把该时刻的通量用于整个时间步。以下用 n 表示步号，Δt 表示步长（秒）。

    Nₙ = SW − OLR(Tₙ) + Fₙ
Tₙ₊₁ = Tₙ + Δt × Nₙ / C
Rₙ = C × (Tₙ₊₁ − Tₙ) / Δt − Nₙ

    Rₙ 表示该步热储存变化率与驱动通量的差。由离散方程可知，它应当只剩浮点舍入误差。要验证的是同一步的温度差与步首通量。由许多步累加的 Nₙ Δt 则可以与首末热储存差 C(Tend − T0) 对比。

    一年固定为 365 天，每天 86,400 秒。默认每年等分成 12 步，每步 2,628,000 秒。用 4×CO₂ 实验手算第一步，初态 T₀ = 288 K，所以 N₀ = F₀ ≈ 7.417 W m⁻²，一步升温约 0.09281 K，步末温度约 288.09281 K。

    固定强迫时，离散步剩余的平衡温差每次乘以 1 − Δt/τ。因此 0 < Δt/τ < 2 时误差衰减，Δt/τ ≤ 1 时从同一侧趋近平衡，比值在 1 与 2 之间时会在平衡两侧振荡。M0 限制 Δt ≤ τ，使固定强迫下的响应单调趋近平衡。基准月步是 Δt/τ ≈ 0.0150。这一计算检验稳定性，精度还要看步长收敛。保持物理参数与总时间相同，步长减半，固定强迫下与连续解析解的误差在线性收敛区间内约减半。

    怎样解读这一层模式¶

    • 这个单一温度和固定反馈描述全球平均响应。区域气候、天气、海冰与碳循环需要额外的状态和过程。
    • CO₂ 是指定浓度，模式解释的是这条浓度路径所产生的辐射响应。把排放换算成浓度需要碳循环。
    • 单箱给出一条快速和缓慢过程合并后的指数响应。要表示混合层与深海热交换，可在下一层加入独立的深海热储库及其交换通量。Geoffroy et al. (2013)

    动手验证¶

    1. 把 4×CO₂ 的热容量改为两倍，保持其他量相同，再画温度曲线。用 τ 和 Teq 预判曲线何处会变、何处会重合。
    2. 在控制实验把初温设为 289 K。从解析解推算 5.55 年和 11.10 年的温度，并用相近的输出时刻核对。
    3. 把 4×CO₂ 分别用每年 12、24 和 48 步运行 20 年，计算第 20 年末温度与解析解的差，并验证两次步长减半的误差比。
